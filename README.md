Look for the latest files, release assets, or source files in the repository.

### 2. Save the files to your computer

If you see a release package, download it and save it in a folder you can find later, such as Downloads or Desktop.

If you see the extension files, download the full folder or ZIP file before moving to the next step.

### 3. Open Chrome

Start Google Chrome on your Windows PC.

Make sure you are signed into the browser if you want a smoother setup.

### 4. Open the Extensions page

In Chrome, enter this address:

chrome://extensions/

This page lets you manage browser extensions.

### 5. Turn on Developer mode

In the top right corner, switch on Developer mode.

This allows Chrome to load an extension from a folder on your computer.

### 6. Load the extension

If you downloaded a ZIP file, extract it first.

Then click Load unpacked and choose the LuminaSider folder.

Select the folder that contains the extension files, not a parent folder.

### 7. Pin the extension

After Chrome loads LuminaSider, click the puzzle icon near the address bar.

Find LuminaSider and pin it to the toolbar if you want easy access.

### 8. Open the side panel

Click the LuminaSider icon in Chrome.

The AI assistant should open in the browser side panel.

If the side panel does not open, refresh Chrome and try again.

## ⚙️ Troubleshooting

### The extension does not appear
- Check that you loaded the correct folder
- Make sure Developer mode is on
- Refresh Chrome
- Remove the extension and load it again

### The side panel is blank
- Check your internet connection
- Confirm the extension has finished loading
- Reopen Chrome
- Try the icon again from the toolbar

### The assistant does not respond
- Check your API key or provider settings
- Make sure the model name is correct
- Reload the extension page in Chrome
- Close and reopen the side panel

### Chrome blocks the files
- Make sure you downloaded the files from the repository page
- Extract any ZIP file before loading it
- Use a local folder on your Windows PC
